# Invite (Annonyx)

Сервис для маркетологов: создание инвайт-ссылок, сбор статистики кликов и управление подпиской.
Домен, под который планируется сервис: `invite.annonyx.ru`.

## Возможности

- Регистрация и вход.
- Создание инвайт-ссылок на целевые URL.
- Просмотр списка ссылок и статистики кликов по времени.
- Пробный период 7 дней, далее 150 ₽/месяц с оплатой через ЮKassa (интеграция подготовлена концептуально, без реальных платежных вызовов).

## Стек

- Go + Gin
- Gorm + SQLite
- HTML/CSS/JS (динамический фронт)

## Быстрый старт

1. Установите Go 1.20+.
2. Запустите приложение:

```bash
go run .
```

По умолчанию сервер слушает `http://localhost:8080`.

## Структура проекта

- `main.go` — основной сервер, маршруты и модели.
- `web/` — статические страницы и скрипты.
- `invite.db` — база SQLite (создается при первом запуске).

## Основные маршруты

- `GET /` — страница входа.
- `GET /dashboard` — дашборд.
- `POST /api/register` — регистрация.
- `POST /api/login` — вход.
- `GET /api/links` — список ссылок.
- `POST /api/links` — создать ссылку.
- `GET /api/links/:id/stats` — статистика кликов.
- `GET /i/:code` — редирект по инвайт-ссылке.

## Примечания для коллег

- Для локальной разработки домен можно подменять через `/etc/hosts`, но фронт выводит только `invite.annonyx.ru` как пример.
- Интеграция с ЮKassa должна быть добавлена в отдельном сервисе или обработчике, чтобы реализовать:
  - создание платежа,
  - вебхуки подтверждения,
  - блокировку доступа после 7 дней без оплаты.
